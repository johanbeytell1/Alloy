FAQ

01 ACCORDION_BLOCKS

01 What defines the Alloy grid?

Every dimension derives from a 0.25rem atomic unit. Components are built on strict multiples of that unit, so borders, padding and type align across any composition without manual correction.

02 Can I override the tokens?

Yes. Alloy exposes its palette and typography as Tailwind theme variables. Override the definitions in your stylesheet and every component inherits the change without edits to the markup.

03 Does it ship JavaScript?

No. The components are pure HTML and Tailwind utilities. Interactive patterns use native elements such as details, checkbox inputs and range sliders wherever possible.

04 Is light mode supported?

No. Alloy is dark-mode exclusive by design. The contrast model depends on deep zinc surfaces and hard white type; a light translation would break the system.

How do I migrate an existing UI?

Map existing spacing to the atomic scale first, then replace surfaces and borders. Components inherit the system automatically.

What about accessibility?

Contrast ratios, focus order and semantic markup are part of the base layer. Interactive demos use native form controls wherever possible.

How are updates delivered?

Pull the repository to get the latest version, then open the explorer and copy only the markup you use.

Is there a Figma library?

A structural Figma mirror is maintained for planning. The HTML explorer remains the single source of truth.
